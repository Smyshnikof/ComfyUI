📋 Как создать токен:
1. Перейдите по ссылке: https://huggingface.co/settings/tokens
2. Нажмите "New token"
3. Выберите "Read" (достаточно для скачивания)
4. Введите название токена
5. Нажмите "Create token"
6. Скопируйте токен (начинается с hf_...)
